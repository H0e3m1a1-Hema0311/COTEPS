# COTEPS Food Experience Platform

Welcome to the COTEPS Food Experience Platform! This project is designed to provide a unique and engaging food experience, setting itself apart from traditional food delivery applications.

## Features

- **Food Discovery**: Explore a variety of foods, categories, and restaurant showcases.
- **User Experience**: Engage with features like the AI Chef Bot, rewards, games, and order tracking.
- **Checkout Process**: Seamless cart management and payment processing.
- **Custom Hooks**: Enhance component functionality with reusable hooks.
- **State Management**: Efficiently manage global application state.

## Getting Started

To get started with the COTEPS Food Experience Platform, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/coteps-food-experience-platform.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd coteps-food-experience-platform
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Run the development server**:
   ```bash
   npm run dev
   ```

5. **Open your browser** and navigate to `http://localhost:3000` to see the application in action.
